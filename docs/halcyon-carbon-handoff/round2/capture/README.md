# Capture harness — NOT RUN in the authoring workspace

This is a reproducible collector to run on the implementing machine, not precomputed goldens. Requires an installed, pinned Playwright package and its matching Chromium. Use your approved existing tooling; if installing anew, install Playwright from its official package, save the resulting package-lock.json and Chromium version with the evidence. No package version was guessed here and there is no claim that the harness has run successfully in your environment. JavaScript syntax was checked only.

1. Copy fonts.example.json to fonts.json. Supply actual local font paths, release/version and source provenance. Use a new output directory for each run. The harness refuses placeholders and missing files.
2. Historical source specimen: `FONT_MANIFEST=/absolute/fonts.json TARGET=historical node capture.mjs`.
3. Cornucopia specimen: `FONT_MANIFEST=/absolute/fonts.json TARGET=native node capture.mjs`.
4. Optional smoke subset: `ONLY=theme-carbon OUT=/absolute/new-output TARGET=native FONT_MANIFEST=/absolute/fonts.json node capture.mjs`. ONLY is a literal scenario-ID substring. Do not label a subset a complete matrix.

Both runs use the pinned committed reference, not the old offline zip. Remote HTTP requests are blocked. Local font bytes are embedded with FontFace and their actual SHA256/version/manifest source are recorded. The historical run uses local supplied Plex fonts; it is a NEW reproducible reference at the old source commit, not proof that those files were downloaded by a historical Google Fonts request. Native mode replaces all Plex Mono CSS declarations with Cornucopia, applies45 contrast amendments, adds the delimiter and changes hints to Super. It retains original mono CSS metrics for comparison; retuning them requires a separately versioned native specimen.

Output per scenario: raw PNG; metadata.json; geometry-styles.json. Every requested matrix/theme/state is generated at both baseDPR1 and2. For matrix scaling see RESPONSE-TO-FABLE: effective browser DPR=scale×baseDPR. No CSS zoom is used, so `vw` and media queries retain the original logical viewport. At100% actual DPRs are1 and2. At200% they are2 and4; metadata does not mislabel them.

The source animations/reduced-motion rule alone cannot freeze caret or transient status reliably. Explicit capture overlays disable animation/transition and force caret visible. Pointer hover is introduced only by named hover/drag scenarios; the picker/help may naturally retain toggle hover from click. If a strict no-toggle-hover popup specimen is needed, move pointer to(0,0) after clicking and record that additional convention. Clock is frozen09:41; status is READY except explicit transient/error specimens. The drag specimen is held at60% with the pointer down, retaining its actual dragging class and glow.

DOM dump records every class/id element plus document block tags, even hidden ones (visible=false). Text-line export contains visible paragraph/heading/list/pre/terminal-line fragments, preserving UTF-16 offsets and Unicode codepoints. Range heights are not baselines; mixed styles can yield multiple fragment groups on one visual line. Clip filtering does not calculate occlusion by arbitrary overlapping overlays: use baseline specimens for text-flow diff and popup specimens for popup geometry.

Pseudo box derivation applies to the pinned absolute divider/header/brand pseudo-elements; border-box and content-box are handled separately. It does not claim general transform/paint-bound support. Important: divider joint has5px content+two1px borders =7px outer. Computed style colors preserve their original serialization and a canvas-normalized RGBA8 sample. Alpha effects need PNG pixels over their real background, not simply the RGBA foreground.

Run the first Carbon specimen, inspect fontFaces and screenshot for fallback, and compare element counts before launching the full matrix. `document.fonts` shows registered faces, not which file painted every glyph; hash provenance is supplied by the exact byte injection. For per-glyph fallback evidence, use your Chromium font inspection tools or dedicated glyph coverage probes. Do not accept a font check that silently substitutes missing Cornucopia λ/box glyphs.

Do not auto-accept generated PNGs as goldens. Review them, then check in source hashes, font hashes, Chromium version, matrix convention and captures as one baseline revision. Repeat on the native framebuffer with the amended target, masking the intentionally changed mono metrics rather than demanding pixel identity with old Plex Mono.

Halcyon — Daylight

visual specification v1 · thylacine

Daylight is the paper-light theme for Halcyon, the graphical shell. It is the calm-day counterpart to Bonfire, which lights the Utopia terminal at night. The two meet inside every pane that hosts a console: Bonfire's background sits unchanged inside Daylight's chrome.

Everything below derives from two commitments. Panes are physical objects lit from the north-north-west. Focus is a property of a tile, not a pane, and it carries the tile's condition at the same time.

Token source: halcyon-daylight.css. This sheet inlines a copy of that file so it opens standalone; the standalone file is canonical.

The bevel is drawn with a real CSS border, not box-shadow. Opaque children paint over inset shadows, and a border reserves layout space that cannot be covered. The same rule applies to the inner hairline and to the cast shadow beneath live content.

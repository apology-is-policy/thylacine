## Fork

fontconfig 2.18.3 registers seventeen compiled C tests. One of them,
`test-d1f48f11`, builds its fixture with `symlink()`, which stays `ENOSYS`
on Thylacine ([[dec-2026-10-20-native-lstat-readlink]]). It fails in its
setup, before it reaches the function it tests. The B-3 test bar
([[dec-2026-10-14-b3-test-bar]]) runs each library's compiled tests and
lists only the interpreter-driven suites as skipped. How should B-3g treat
this one?

## Research

- The test (`test/test-d1f48f11.c`) makes `conf.d/00-foo.conf` a relative
  link to `../conf.avail/00-foo.conf` in a `mkdtemp` directory, then checks
  `FcConfigRealFilename` twice: once plainly, once under
  `FONTCONFIG_SYSROOT`. Its `setup()` returns 1 when `symlink()` fails.
- `FcConfigRealFilename` (`src/fccfg.c`) resolves a link with `readlink`.
  Every config load calls it (`src/fcxml.c`) for each file it includes. On
  the device that is the 23 relative links in `/etc/fonts/conf.d`, which
  the bake puts as links. So the plain half runs on every load, and
  `ls-libs.exp` checks that `fc-conflist` loads every one of them.
- The `FONTCONFIG_SYSROOT` half has no other coverage on the device.
- No other compiled fontconfig test makes a link. The library's own
  `symlink()` call names older cache versions after the current cache file
  (`src/fccache.c`); it ignores the failure.

## Options

- **List it as not run.** The manifest tool takes a compiled test by name
  with a reason, writes both into the manifest, and stages nothing for it;
  the browser-status row names it.
- **Require its failure.** muster learns an expected failure, and the gate
  checks that the test's log shows `symlink` answering `ENOSYS`. That
  witnesses the missing call but never exercises the function.
- **Make `symlink()` work.** This revisits vote 10: a native `SYS_SYMLINK`,
  the 9P create, Pouch's `symlink`/`symlinkat`, and an audit round, as a
  new chunk ahead of the B-3g close.
- **Patch the fixture** onto a link baked into the pool. This rewrites
  upstream's test, and the baked tree is read-only, so the sysroot half
  would need a second baked copy.

## The call

List it as not run, with this decision as the reason (operator vote,
2026-10-21).

## Rationale

The test cannot reach its subject without a call Thylacine has chosen not
to provide, so running it measures only that choice. Its plain half is
exercised on the device by every config load, through real links, and a
gate checks that. A named, reasoned entry keeps the gap visible: the
manifest refuses a not-run name that upstream does not register, and the
sysroot half comes back the day `symlink()` exists.

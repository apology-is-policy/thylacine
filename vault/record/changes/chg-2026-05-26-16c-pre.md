Two unblocks for stratumd's listener. 0014 stubs `lstat`/`unlink`/`chmod`
on `/srv/` paths so the idiomatic unlink-then-bind dance proceeds -- each
answer is a Plan-9-shaped truth (there is no file inode at `/srv/<name>`),
and a genuinely-taken name still fails at `bind`.

0015 closes the gap sub-chunk 12 left: `poll()` was the one fd-consuming
call with no tag dispatch, so stratumd's `poll(listener)` got `POLLNVAL`,
its accept loop bailed on the `POLLERR|POLLHUP|POLLNVAL` idiom, stratumd
exited, and joey's unfiltered `wait_pid` reaped the wrong pid -- a chain
that ended in kernel extinction.

`struct t_stat` gained `u32 devno`@80 (Plan 9 `Chan.dev` / POSIX
`st_dev`), filled by `spoor_stat_native` and — the stalk hook — stamped
onto the POUNCE walk-query fast path from the run parent (the fused
leaf inherits the session identity, matching the fallback path
byte-for-byte). Consumer: gopls robustio `FileID{Dev, qid.path}` (two
files with equal qid.path in DIFFERENT sessions must not alias). The
mirror-lockstep lesson lives in the commit body: a per-mirror
`_Static_assert(sizeof==N)` verifies only THAT mirror — two stale pouch
patches passed the build and overflowed at runtime, caught by a boot
segv + grep, not the assert. Regression
`spoor.stat_native_stamps_devno`; all six `.stat_native` impls zero the
full struct so the new pad cannot leak (I-13).

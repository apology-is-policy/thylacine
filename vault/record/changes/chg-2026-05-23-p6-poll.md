`__NR_poll = 29` reinstated (Linux aarch64 dropped legacy `poll` in
favor of `ppoll`, so the pristine table has no entry) which activates
musl's own `#ifdef SYS_poll` branch; `select` and `pselect` rewritten to
translate `fd_set` <-> `pollfd` in userspace, since the kernel speaks
only `pollfd`.

The fd-VALUE bound written here as `PROC_HANDLE_MAX = 64` was correct at
the time and became wrong when the fd table grew to 256 (#355) -- see
[[seam-pouch-select-fd-bound]].

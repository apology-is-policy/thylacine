Round 7, Opus on Opus, on the merged tree: 0 P0, 0 P1, 1 P2, 9 P3, all read from the code. Two P3s fall on the join.

- **`ls-graphical-sak-poison`'s witness could never pass.** Its `control` and `poisoned` stages were not stages the probe knew, so it exited 2 printing nothing and the leg timed out before the poison was armed. Both are plain stages now. Vote 50's reproduction depends on this leg.
- **`tools/check-expect-forms.py` read too few forms.** Measured on expect 5.45: every flag before a block arms nothing, including `-iread`, `-timestamp`, `--` and abbreviations such as `-notr`. So do `expect { -re foo }`, `expect { timeout exit }`, and the same blocks on `expect_before` and `expect_after`, which go by the same rule. `eval expect {{...}}` is live, because `eval` strips a level of braces, so a wait behind `eval` or `uplevel N` is a hit to write directly. The self-test holds 32 bad rows and 23 good ones, and the tree is clean.

The auditor also called `expect -timeout 5 $pat` a false hit. It stays a hit: a variable may hold a block, and this cannot see which. `"$pat"` says it is one pattern.

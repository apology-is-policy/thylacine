Round 1 on the slab, ptyfs and console chunks, before any boot. `slab_refusal.clone` could never pass: a writable eager mapping refuses the fork before it asks for a Vma, so every boot of the branch would have extincted. It maps lazy Burrows now, plus a read-only eager one, and asserts no Burrow leaks. A slab-refused segment or stack made exec report EINVAL, a malformed binary's code: `burrow_map_in` asks `vma_shape_ok` first, so `vma_alloc`'s NULL can only be a shortfall, and says ENOMEM. A signal byte behind a refused newline in one write was held and then dropped with the buffer; it now reads past the held byte, discarding what was typed before it and not delivered, in raw mode too. An echo goes whole or not at all, and a lost echo no longer spends the one-shot report that a lost input byte needs. Stale text corrected in the dossiers, `spec-pty`, ARCH and AUDIT-TRIGGERS, including this branch's own claim that `^C` is not held up, which was true only for a later write.

Inherited and open: a paused RX on the serial console leaves `^C` and BREAK unread in the FIFO while nothing reads the console. That needs a vote.

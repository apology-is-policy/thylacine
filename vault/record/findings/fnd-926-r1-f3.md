## Prosecution

In the U-6f command-substitution consumer, a spawn failure can set the
`Cell`-backed `$status` but not `$errstr`, which is `&mut`-only and
unreachable from the `&Env` the substitution path holds. So a failed
substitution reports the right status with a stale error string.

## Disposition

CLOSED WITH JUSTIFICATION, no code change: the failure remains observable
via `$status`, and the limitation was already documented in `stmt.rs`.

Recorded on this surface because it arrived in the #926 round; the code is
userspace shell and will re-home to the shell area's own dossier when that
is swept.

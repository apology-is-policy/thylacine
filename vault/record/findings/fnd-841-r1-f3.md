## Prosecution

The section-21.10 sketch prose described a block-on-room send; the as-built
srvconn_client_send_frame returns 0 on a full ring and the caller marked
the session dead. A deep burst could kill a healthy session.

## Disposition

Reconciled as documentation at the time (bounded + dormant at the v1.0
single-in-flight workload; ring = 2x msize). NOTE: this "dormant" P3 became
the live #349 P1 class once the go build made concurrent large frames real
-- the lineage's congestion-is-not-death lesson traces to here.

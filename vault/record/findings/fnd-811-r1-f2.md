## Prosecution

`rendez.death_interrupts_sleep` set `g_death_proc->state = 2` rather than
`PROC_STATE_ZOMBIE`. Brittle against an enum renumber — and the enum
deliberately reserves 0 for INVALID, so renumbering is a live possibility
rather than a hypothetical.

## Disposition

FIXED to the named constant. Noted at the time and NOT swept: `test_torpor`'s
`torpor_consumer_teardown` still carries the same literal — a pre-existing
instance left untouched rather than folded into an unrelated close.

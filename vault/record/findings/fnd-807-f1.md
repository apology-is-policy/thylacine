## Prosecution

`my_cpu()` = `MPIDR_EL1.Aff0`, clamped. On a clustered big.LITTLE
SoC Aff0 REPEATS per cluster (cluster 0 CPU 0 and cluster 1 CPU 0
both read Aff0 == 0) — two CPUs fold onto one magazine set, and the
IRQ mask pins only the LOCAL CPU: the exact shared-set double-alloc
race #807 closed, reopened by topology.

## Prosecution

Nine blocking sites grew an explicit `*_INTR` arm at #811. Torpor was the
tenth and got none: it absorbed the new return by falling through its
"non-TIMEDOUT counts as OK" branch.

Behaviourally correct, and verified so — `SYS_TORPOR_WAIT` returns through
the standard syscall tail, whose `el0_return_die_check` self-terminates the
Thread before it can resume userspace, so the fabricated OK is never
observed and the bucket is already unlinked. But the correctness depended on
a coincidence of control flow that nothing stated.

## Disposition

FIXED with an explicit comment at the `return TORPOR_OK` documenting the
deliberate `TSLEEP_INTR -> TORPOR_OK` mapping and why the return value is
immaterial. No behavioural change.

Recording it as a finding rather than a tidy-up is the point: an implicit
absorption that happens to work is one refactor away from a lost death.

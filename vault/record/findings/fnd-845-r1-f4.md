## Prosecution

The early consume set out->kind then returned 0 ("completed") -- a
misleading partial result on the ownerless path (the sole caller discards
*out, so it was dead code wearing a live contract).

## Disposition

Fixed: dropped the write; out stays zeroed; the 0 return documented as
"ownerless late reply absorbed", not "op completed".

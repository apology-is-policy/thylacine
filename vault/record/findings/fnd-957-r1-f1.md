## Prosecution

`sys_walk_open_handler` treated `Dev.open`'s return as a bool
(`if (!opened)`), but `devsrv_open` is the ONLY user-reachable Dev
whose open returns a DIFFERENT Spoor (open=connect). The #957 cross
made a `/srv` registry root a natural single-hop-walk parent, so
`File::open("/srv/<name>")` (non-O_PATH) reached `devsrv_open_connect`
— which mints a SrvConn and returns the endpoint — but the handler
installed the SPENT service-ref `nc` and never installed or clunked
`opened`: a permanent leak (endpoint Spoor + SrvConn + a poster backlog
slot) plus the WRONG handle. Pre-existing (the bool treatment predates
the diff), exposed by the new reachability. Crash-safe: leak +
wrong-endpoint, not UAF.

## Disposition

Fixed in-commit by adopting open()'s return exactly like stalk's
audited arm (clunk the spent quarry, adopt the replacement) — which
also makes the single-hop `/srv` open CONNECT correctly. The
enforcement site is syscall-side (that surface's sweep owns the deep
detail); filed on devsrv, whose connect contract was the victim.

append links once; take resets tail after last element, removes the popped link
and consumes dirty. Start only NEW prevents duplicate roots/restarts; kick does
not create a root. PARKED kick transitions to READY; RUNNING dirty survives the
last-observation/finish interval. Finish returns a distinct DROP action only
for complete and gives completion precedence over stale more/dirty. Otherwise
immediate useful work or an external dirty event requeues; blocked work parks.

keep it across READY/RUNNING/PARKED and drop outside Q after complete. No memory
allocation, scheduler wake, callbacks, final drops or Loom lock in module.

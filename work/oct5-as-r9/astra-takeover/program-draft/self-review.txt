This layer adds staged GETATTR -> permission decision -> WALK/LOPEN, over the
verified wire adapter. Nonempty WALK first requires the source QID to identify a
directory (NOTDIR before DAC), then ordinary PERM_X search. Empty clone performs
no path traversal and goes directly to Twalk with zero names. LOPEN first rejects
P9_QTSYMLINK with LOOP, preserving the ordinary SYS_WALK_OPEN rule: a link's 0777
cannot authorize opening its target through a server-dependent interpretation.
It then uses perm_want_for_omode for exactly mode 0/1/2 and the actual existing
perm_check_identity. No new privileged principal or worker authority is added.

Each program holds a detached ProcAccessIdentity value for this operation.
The integrating constructor MUST supply the creator/image's new snapshot, never
protocol->identity cached at CONNECT. Value copying holds the admission-time
caps and supplementary groups through retries; another call cannot recapture an
already-started program. Native private service IDs use the local authority
namespace, not foreign cape mount translation. Header comments make these caller
requirements explicit. This layer does not itself pin a creator or sample Proc.

GETATTR must have all mode/uid/gid fields. Malformed capture, inconsistent stage,
uncaptured success, incorrect expected frame or a duplicate program completion
requests whole-scope abort. Ordinary negative remote results stage a terminal.
Only the wire adapter's submit-return no-wire proof allows EAGAIN retry. Thus a
later remote EAGAIN remains terminal even after earlier local backpressure.
Permission refusal stages a negative result without ever sending the effect.
Successful stat merely selects the next step; successful WALK merely stages 0.
The owner still publishes the exact reserved destination under Ll, mapping it to
the destination slot result only after abort/deadline and physical lifetime gates.

No callback advances the program. The sole driver calls it after actual client
return, with callback/phase guards and retained request borrow. NEXT cannot bypass
Ll rechecks of READY/abort/close/absolute deadline before another wire effect.
TERMINAL is a tentative program outcome, not a request terminal or CQE. Physical
FID/buffer cleanup must finish before the request borrow ends; CQ pressure cannot
hide or free an operation. ABORT must execute actual client abort/quiescence.
READ/WRITE/CLUNK enter effect directly only because the future admission layer
must already enforce exact mapped FID rights, CLUNK drain and canonical payload
ownership. This helper is not a substitute for those still-unimplemented checks.

Astra single-agent self-review: fixed request deadlines/cancellation, October10.
Uninstalled Rust draft with simulated backends, not an independent audit.

Deadline and abort-requested bits reside in the existing 64 fixed-owner cells.
No extra timer nodes, growing queue, borrowed request pointer or numeric handle
is exposed. set_deadline is allowed only before local publication; after that
neither activity nor caller replacement can extend it. None means no local timer;
this Option is not the native zero encoding. Only active, not-yet-cancelled cells
contribute to next_deadline. Terminal and prepared cells do not. Publication
signals local progress so an adapter can recompute its next wait deadline.

expire visits at most min(budget,64) cells, rotating its cursor. Zero budget is
no work; it does not pretend an overdue timer was processed. A future event-loop
must continue bounded scans while next_deadline remains due, rather than sleep.
Cancellation checks exact owned cookie/index and marks abort-requested before
calling the backend outside the inner cell borrow. The backend retains its
nonblocking/nonreentrant/idempotent scope-abort contract. It may affect siblings;
this is deliberately scope-wide, not per-request remote cancellation.

Explicit cancel, expiry and active-handle drop issue at most one abort per fixed
owner. Multiple siblings may independently request the same idempotent scope
abort. Requests, completion metadata and backing remain owned after cancellation.
No timer or abort acknowledgement supplies local quiescence, terminal CQ, remote
rollback or refund. Authentic terminal completion can still return a successful
WRITE after a cancellation request; the result is preserved. Abandoned requests
retain correlation until CQ or whole-owner retirement. Closed owners issue no
further backend aborts. Reused cells initialize both timer and cancellation state.

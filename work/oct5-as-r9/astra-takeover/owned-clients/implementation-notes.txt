Required implementation boundaries:
1. Dedicated private wrapper consumes Ring and RegisteredBuffer ownership; it
   must not expose legacy reap/raw submit or mutable backing after admission.
   Consume owned eager storage, never treat raw integer registration as safe.
2. Reap copies CQE and paired receipt before one release-store of CQ head;
   preserve correlation, MORE/final, exact slot/incarnation/member/lease identity.
   Validate geometry and result length before forming any payload slice.
3. Owned PayloadLease retains pool/storage, offers read-only view tied to lease
   borrow. Drop/return cannot recycle while Rust borrows live. C opaque lease has
   explicit release and documented no-further-access obligation. CQ ack and
   final stream completion never return previously transferred payload leases.
4. Future drop requests scope abort, not storage reuse. Client drop retires through
   a bounded owner list; errors retain ownership until return or demonstrated
   whole-owner close/retirement, with kernel pins preserving actual payer budget.
   Keep list capacity within existing admitted ring/slot bounds; no new allowance.
5. Preserve errno categories rather than raw Ring's InvalidArgument collapse.
   Carry phase/BYTES_SENT diagnostics; cancellation after write remains unknown
   remote outcome, never promise rollback. Cancellation is scope-wide explicitly.
6. Drive fixed-size pending/lease bookkeeping and retire list without blocking
   UI or depending on peer progress. Inspect existing scheduling/client owners
   before choosing integration mechanism; approved Halcyon control executor
   remains the owner, no new thread or kernel ABI inferred here.

Tests required before activation:
- host actual-source ownership tests and Rust compile-fail examples for mutable

- distinguishable A/B payloads, retained A while B progresses, stale/double/out-of-
  order returns and pool incarnation reuse, returned-error retention;
- abandoned future/client with outstanding requests and leases; exact eventual
  refund, full CQ/empty pool, bounded failed-return retirement list;
- native wrappers in explicitly qualified image without default activation,

Astra single-agent self-review: fixed Rust Futures, October10.
Uninstalled simulated-backend adapter; not an independent audit or native pass.

Read/Write Future owns the existing typed request; no borrowed pending buffer or
second backend close owner. Hub reserves one of64cells before request preparation,
rolling back failure. This matches the conservative existing fixed-buffer bound.
Completion or Future drop detaches its registration exactly once. Request drop
still preserves active storage and requests scope abort; unregistering a Waker
never grants reuse. Completed READ results keep their own backing. WRITE returns
actual terminal result; Closing never proves remote rollback or no bytes sent.
Root shutdown closes the existing driver, detaches future delivery, wakes pending
tasks and retains live storage through the already-tested request owners.

Single-creator Rc prevents Send/Sync. Wakers may schedule tasks from another thread;
all actual driver/request operations remain creator-thread only. Completion wakes
a bounded snapshot of at most64 registered tasks; spurious wakes/coalescing are
intentional, and readiness is always rechecked by polling. Wakers are taken from
slots before invocation. Clone occurs BEFORE readiness check so a clone callback
that delivers completion cannot produce stale Pending. Replacement is published
before old Waker drop; replacement/drop/wake callbacks execute outside Hub and
FixedDriver RefCell borrows. Safe Waker callbacks are external code and may
allocate: the no-allocation assertion covers this adapter with ordinary Arc
Wakers, not arbitrary user vtables. No blocking/waiting or native SQ occurs.
